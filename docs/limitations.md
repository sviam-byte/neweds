# Ограничения

- Проект не является медицинским диагностическим инструментом.
- Group-level outputs являются exploratory и требуют независимой статистической проверки.
- Directed-метрики чувствительны к preprocessing, длине ряда и выбору лага.
- AR/STL-preprocessing может менять временную структуру, которая важна для lag-based метрик.
- Метрики с названием `partial` могут иметь разную математическую семантику.
- HDF5/fMRI-like поддержка является экспериментальной.
- Результаты зависят от качества данных и выбранных параметров preprocessing.
