# Архитектура

NewEDS устроен как небольшой scientific Python pipeline.

Основной путь:

```text
таблица временных рядов
-> загрузка данных
-> preprocessing
-> расчет метрик связности
-> матрицы и сводки
-> HTML/Excel-отчет
```

Ключевые части:

- `neweds.core.pipeline` запускает анализ одного файла.
- `neweds.core.preprocessing` готовит временные ряды к расчетам.
- `neweds.metrics` содержит реализации метрик и их регистрацию.
- `neweds.reporting` собирает HTML/Excel-отчеты.
- `neweds.cli` дает команду `neweds` для терминала.

Group pipeline и voxel/HDF5-инструменты считаются экспериментальными. Они оставлены в проекте, чтобы показать работу с менее чистыми исследовательскими данными, но не являются главным стабильным сценарием.
